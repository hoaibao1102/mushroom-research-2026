## Objective and method

Audit the expanded M18K V2 dataset's RGB/depth file inventory, COCO segmentation labels, class balance, object density, bounding-box integrity and potential evaluation leakage. The notebook iterated over large COCO JSON files using a streaming parser, then made sampled visualizations. Its saved output is the evidence for the counts below. **The full data was not uploaded with this Git repository, and this integration did not independently rerun the complete V2 analysis.**

These splits correspond to ~80/10/10, unlike the 70/10/20 protocol described for the paper's separate 2,000-image benchmark. The source release had reportedly been described as 4,652 images; the **157-image discrepancy** between that figure and the 4,495 annotated RGB entries has not been resolved. Do not assume files are missing before checking source counting conventions.

## Key findings

**Severe class imbalance:** Raw COCO category names map category ID 1 to Baby Bella (BB) and category ID 2 to White Button (WB). The notebook counts **858 BB (0.122%)** and **699,731 WB (99.878%)**, approximately 816 WB instances per BB. BB appears in 650 of the 4,495 images. This is a measured annotation distribution, **not confirmation that every BB/WB assignment is correct**. Rare-class review is necessary before reporting per-class recognition performance.

**Crowded scenes:** The number of annotated instances per image has median **166**, 10th percentile **86**, 90th percentile **201**, minimum **4**, maximum **222**. High object density suggests an important small/overlapping-instance evaluation challenge. The box size plot is sampled, whereas class and image counts are full annotation counts.

**RGB-D data:** The notebook matched all 4,495 RGB image filenames with depth files in the corresponding split. Sample depth visualizations were produced. This supports file pairing only: **intrinsics, metric scale, alignment and data validity for every pixel are not established**.

**Annotation format and basic QC:** All 700,589 annotation records were identified as polygon segmentation. Six bounding boxes had non-positive width or height. The basic check reported no missing segmentation representation, but did not adjudicate each polygon or resolve boxes; annotation correctness is not a proven near-perfect success rate.

**Leakage:** Exact filename overlaps across train/validation/test were reported as zero. **Complete image SHA-256 hashing was disabled** and near-duplicate, scene, batch and temporal leakage checks have not been performed. A safe independent test split remains unverified.

## Scientific interpretation

The current data-processing workflow is operational and provides a substantial EDA record, but the dataset has unresolved label and independence risks. We should treat V2 as a *distinct experimental release*, not equate any future Ultralytics mAP@50 / mAP@50:95 directly with the original paper's reported AP without matching metric definitions and test protocol.

No V2 training was completed in this notebook (`RUN_TRAIN=False`); **no precision, recall, AP or mAP result for a trained model is available**. Published paper AP values are literature benchmarks, not team results.
