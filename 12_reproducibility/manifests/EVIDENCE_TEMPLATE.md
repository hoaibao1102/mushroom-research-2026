# Evidence record template

Copy and complete only when evidence exists. This is a template, not a scientific record.

- Evidence ID / candidate / claim:
- Tag: VERIFIED_FACT | SOURCE_CLAIM | PRACTITIONER_OBSERVATION | HYPOTHESIS | UNKNOWN
- Source URL and exact section / artifact relative path and SHA-256:
- Source version / collection or access date / reviewer:
- What was actually checked; method/command:
- Supported scope / uncertainty / contradictory evidence:
- Dataset-paper identity relationship and exact matching evidence, if relevant:
- Follow-up / decision ID:

A source claim is not an independently verified fact. A hypothesis is not a confirmed research gap. Do not place data payloads in this directory.
