# Day 8 — 10 November 2026

## Local application prototype

A first Streamlit prototype was assembled from the Day 6 system requirements and architecture. It connects cultivation records, image capture, model-bundle management, segmentation inference, tracking, image-space growth measurements, maturity grouping, environmental records and human review/export.

The prototype snapshot is retained under `13_local_application/` for traceability. The research repository remains responsible for research methods and evidence; active application development is intended to continue in a separate repository. Its URL is still to be added to the root README.

## Validation

- Application unit tests: **7/7 passed**.
- The packaged system check found one active MushR model-registry entry but no checkpoint file. It did not run trained-model inference.
- Validation ran with CPU-only PyTorch in a Linux environment. DirectML was unavailable; AMD acceleration on the target Windows/RX 5500 XT remains unverified.
- Physical area, multi-species accuracy and field performance remain unvalidated.

The prototype is an application milestone, not evidence that either oyster model is accurate enough for deployment. The Charisis temporal-tracking and MushR per-image grouping semantics remain distinct.
